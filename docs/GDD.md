**显示缩放方案（网格已定为 192×160，这里只决定"怎么放大到屏幕"）**

- 网格定为 **192×160** 后，**不再存在 Atari 原机那套 1.6:1 非方形像素**的问题 —— 直接按方形像素整数倍放大即可。
- 推荐：窗口 **768×640**（4×）或 **960×800**（5×），`Stretch Mode = viewport`、`Aspect = keep`、`Scale Mode = integer`。像素锐利、比例不失真、itch 嵌入也放得下。
- 备选：若想让画面显得更"宽银幕"，可把窗口设成 4:3（如 1024×768）并配 `Aspect = expand` —— 但这会**改变像素形状**，与"192×160 网格"的既定规格冲突，除非两人都同意。
- ⚠️ 前提是**不要在窗口比例上追求 4:3**：一旦追求 4:3，192×160 的内容就会被拉伸变形（192/160 = 1.2，而 4:3 = 1.333）。

**音频方向（Ray）**

- TIA 风格：2 声道、方波为主 + 噪声，短促、颗粒感强。
- 提交前转 `ogg`，避免 wav 撑大仓库。

**主题投票进展（2026-09-22 进行中）**

- 候选：① Horror ② Anime ③ Speed ④ Cat ⑤ 4th wall break。
