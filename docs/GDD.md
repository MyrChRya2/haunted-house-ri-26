## 四、Jam 规则硬约束（不可谈判，2026-09-22 摘自 jam 页）

1. **No generative Ai!** —— 不得使用生成式 AI 产出。**本项目管理 Agent 是 AI**：用它产出素材、文案、代码是否算违规，必须先向主办方 Discord 问明；未问清前，AI 只做**项目管理**（文档、表、排期、Git 命令），不产出游戏内容。
2. **游戏必须在 Jam 期间制作**；仅允许**少量**预制素材且需正确署名 —— 准备期只做技术准备与少量素材，不得把游戏本体提前做完。
3. 任意引擎可，但**强烈推荐浏览器可玩** → Web 导出为第一目标。
4. 禁止仇恨言论与 NSFW；尊重他人，不得操纵评分。
5. 加入 Discord 投票选主题、领奖。

> 评审标准：Fun / Theme usage / Visuals / **Atmosphere（是否像复古游戏）**。
