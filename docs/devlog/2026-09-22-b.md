## 踩坑 / 问题

- **`bitable_setup` 报 `code=99991672` 三次** → 根因是"创建版本=权限快照"：先建版本、后开权限，则该版本不带权限，发布也无效；应用详情页显示"已发布"极具迷惑性。解法：开通 `bitable:app` + `drive:drive` 后**另建一个新版本**发布。
- **飞书 API 只能靠 pwsh 出网调用** → `Invoke-RestMethod` 撞上未开启的 socks5 代理（connection closed）；`curl.exe` 又被沙箱拒绝（Access is denied），需一次性 `danger-full-access` 授权才能跑通。
- **免审批改不了 preset** → DSH 的 sandbox / approval 归宿主，preset 文件里写明 `preset must not own: ... the sandbox and approval`。要免审批只能放宽宿主沙箱，或把飞书 API 做进插件（需重启 `dsh web`）。
