# Haunted House — R&I 26 RE

> 二创重制 Atari 2600《Haunted House》(1982) 核心机制的顶视角恐怖游戏。
> A top-down horror remake of the core mechanics of *Haunted House* (Atari 2600, 1982).
> 制作于 **Retro Game Jam 2026**，由 **R&I — Ray & Illya** 两人完成。

- 🎮 网页可玩 / Playable in the browser: <https://myrchrya2.itch.io/haunted-house-ri-26-re>
- 🕹️ 操作 / Controls: **W A S D** 移动 · **E** 交互（划火柴 / 确认）
- 🧩 引擎 / Engine: **Godot 4.7.1** (standard build) · 网页导出 `gl_compatibility`

---

## 这个仓库里有什么 / What's in here

```
docs/                 设计与项目管理文档（GDD / ROADMAP / devlog / itch 页面文案）
retro-game-jam-2026/  Godot 工程本体（游戏代码、场景与美术音频素材）
```

- `docs/GDD.md` —— 设计宪法：模块归属、视觉音频规格、二创接口、规则与 AI 红线、不做清单
- `docs/ROADMAP.md` —— 时间盒、里程碑、决策记录、Bug 跟踪
- `docs/ITCH_PAGE.html` —— itch 商店页文案（中英双语）
- `docs/devlog/` —— 每日开发日志
- `retro-game-jam-2026/` —— 用 Godot 4.7.1 打开这个目录即可运行（主场景 `scenes/levels/level/title/title.tscn`）
